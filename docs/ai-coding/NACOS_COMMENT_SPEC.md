# Nacos 配置注释与归类规范

本规范适用于本项目族维护的 Nacos 配置、可提交模板、私有渲染结果及配置发布工具。Yudao 项目不在此次同步范围内，不因本规范批量修改其文件或配置中心内容。

## 必须说明的内容

- **每个 dataId 必须有文件说明**：职责分类、用途、适用环境、group、namespace 的来源、当前导入服务或消费者，以及相关配置的引用关系。敏感环境地址和凭据不写进注释。
- **每组配置必须有清晰边界**：按共享变量、共享基础设施、安全与可观测性、共享 AI 协议/模型、服务专属、服务框架等职责归类。维护分类索引，保留既有 dataId、group 和 import 契约；不得为排版任意拆分或重命名。
- **每个可调参数必须有有效注释**：说明作用、单位、可接受值或格式、默认值/空值的意义、开关关闭后的行为，以及需要联动的调用方。单位不明或框架不再消费的历史键必须如实标记待核，不能猜测或暗中删除。
- 地址区分协议、主机、应用端口、控制台端口与 gRPC 端口；超时区分毫秒/秒，容量区分字节/MiB，缓存过期时间说明单位。
- 路由和有序列表必须说明匹配顺序、原生路径、前缀剥离及兜底规则。认证、租户、数据权限、灰度、限流、公开访问和日志类参数要说明边界及开启/关闭的影响。
- 凭据只注释用途、来源与必要权限，不复制真实值。公共模板仅使用占位符；环境变量名称与运行时 Spring 占位符不能混淆。注释中同样禁止密钥、令牌、生产内网地址及人员/业务数据。
- 空配置也必须说明为何保留，以及是否仍有消费者导入；空映射不等于可删除。

## 文件格式

- YAML 使用独立的 `#` 注释行，放在对应配置组或参数上方，缩进随字段；不要把实际配置注释掉。仅短单位说明可以使用行尾注释。
- Properties 使用 `#` 注释，说明键的作用。标准 JSON 不支持注释，不插入 `//` 或 `#`；使用同名说明文档、配置描述或项目既有支持的格式，不能导致解析失败。
- XML 使用合法 `<!-- -->` 注释。其他格式按其解析器规则处理，不能统一强塞 YAML 注释。
- 注释说明维护意图和实际约束，不写“设置地址”“开关配置”等无信息翻译。既有文件语言与项目约定保持一致。
- 注释、分类索引、模板和实际 Nacos 内容必须同步维护；渲染/导出工具必须保留注释，不得经过普通 load/dump 后默默丢弃说明。

```yaml
# 分类：共享基础设施；用途：个人 Redis 连接。
# 适用环境、group、namespace 和导入服务由当前环境清单确定。
redis:
  # 逻辑库编号，需在 Redis 服务端支持范围内；与共用实例的其他环境隔离。
  database: ${PERSONAL_REDIS_DATABASE:12}
  # 认证密码由私有配置注入；空值是否允许取决于服务端认证策略。
  password: ${PERSONAL_REDIS_PASSWORD:}
```

## AI 修改与发布步骤

1. **盘点和排除**：按当前明确的仓库与环境清单读取配置，排除 Yudao 及未授权环境；核对所有实际 dataId 与本地模板，发现额外配置先确认归属，不能只数本地文件就声称检查全部。
2. **读权威值并备份**：发布前从目标 Nacos 读回内容和 metadata，在 Git 外以受限权限保存快照；没有当前快照时可以整理模板，但不能用旧渲染结果覆盖远端。
3. **保值整理**：注释和归类任务不改变实际键名、类型、值、占位符、列表顺序、import 顺序、namespace、group 或凭据。不得借整理启用功能、关闭鉴权、改变数据源或修复无关业务问题。
4. **证明等价**：解析整理前后内容，逐键、逐类型、逐列表顺序比较；另核对占位符和引用链。重复键、未解析引用或差异必须停止并说明，不以文本差异小或 YAML 能解析代替语义验证。
5. **验证完整产物**：检查私有渲染结果仍包含文件说明和参数注释，真实值不会破坏引号、换行和 YAML 类型；日志只打印 dataId、数量、摘要和校验结论。
6. **受控发布和读回**：按已有授权发布到明确环境，使用 CAS 或等价的旧版本比对；遇到并发漂移停止，不强制覆盖。发布后逐 dataId 读回内容与 metadata，确认注释保留、语义等价，并核对相关服务健康。
7. **交付分别报告**：列实际处理的环境/dataId 数量、排除项、Git 状态、配置发布与读回、运行态验证及未完成项。网络不可达时明确“模板已整理、远端未发布”，不能声称 Nacos 已更新。

## 完成检查

- [ ] 文件职责、环境归属、消费者和分类索引齐全。
- [ ] 每个可调参数有用途和必要的单位、格式、空值/开关说明。
- [ ] 配置有效内容、列表顺序、占位符和隔离边界保持不变。
- [ ] 渲染后的注释仍在，特殊字符凭据不会变成额外 YAML 字段。
- [ ] 真实凭据和私有快照未进入 Git、Wiki 或公开日志。
- [ ] 发布使用已复核旧快照，读回结果与候选一致；未发布或未验收明确列出。
